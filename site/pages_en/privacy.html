Privacy

Vikey processes keystrokes locally on your Windows PC. The text you type is not sent to a server.

What you type

Vikey uses the Windows keyboard hook and local typing engine. Your typed text is not collected or transmitted.

Website addresses

If enabled, per-website language memory reads the active tab's domain in supported browsers using Windows UI Automation. The domain is used only to remember your language choice locally.

Update checks

Vikey may connect to the release server to check for updates. Update requests do not include the text you type.

Bug reports and feedback

Information is sent only when you submit feedback or agree to send a crash report. Crash reports do not contain the text you type.

This website

vikey.app uses no cookies and does not track visitors.
