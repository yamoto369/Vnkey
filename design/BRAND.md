# Vikey brand guideline

These rules apply to the Windows application and the Vikey website.
Implementation: `Windows/App/` for the app and `site/style.css` for the website.

## Name and tagline
- **Vikey**: capital V, the rest lowercase, one word. Never "ViKey", "VIKEY" or "Vi Key".
- Tagline: **Vikey - Gõ tiếng Việt** (page titles, social previews and the app's display name).
- In running text the name is plain text in the surrounding font and color: "Vikey tự chuyển…".

## Wordmark
- "Vi" in ink, "key" in brand indigo, same font, **bold (700)**, no letter-spacing, never all caps.
- Use it wherever the name stands alone as a logo: website header, demo labels, app window headers and About.
- Usually next to the icon, gap ≈ 0.3 × the text height.

| | Light | Dark |
|---|---|---|
| "Vi" (ink) | `#111318` | white / label color |
| "key" (brand indigo) | `#4F46E5` | `#8C87FF` |

## Colors
- **Brand indigo** `#4F46E5` (dark mode `#8C87FF`), hover/pressed `#4338CA`. The only accent color: buttons, links, the wordmark and highlights.
- Ink `#111318`, muted text `#5B6472`, lines `#E6EAF0`, chip/tint background `#EEF0FF` (or brand at 14% on any background).
- Status only: green for "done/added", red `#D14343` for "wrong".
- **No pink, no second accent, no gradients on text.** A soft indigo glow behind hero art is fine.

## Typography
- Use the native system UI font stack; prefer Segoe UI on Windows and system-ui elsewhere on the website.
- Monospace: Cascadia Code or Consolas on Windows, with a generic monospace fallback.
- Headlines 800 (web) / bold (app); body regular. Short lines, no orphans, no split phrases.

## Icon
- Windows app icon: `Windows/App/Vikey.ico`; website icon: `site/assets/icon.png`.
- Keep the white "Vi" on an indigo rounded square. Don't recolor, outline or put it on a busy background.
- Small sizes: 16–34 px with a radius of ~22% of the size.

## Voice
- Vietnamese first, English as the second language of every page and the app.
- Short, concrete, no hype: say what happens ("gõ \"treen\" ra \"trên\""), not adjectives.
